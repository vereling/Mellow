# Mellow

A quiet multitrack studio in the browser.

Layer loops and one-shots, or import your own audio. Each track has its own volume and reverb. The project strip adds a second reverb across the whole mix. Save a `.mellow` project to your computer, open it later, and export the mix as WAV or MP3.

## Use it

- Press play, or hit space.
- Tap a sound to drop it on a new layer. Drag it onto a track to place it.
- Trim or move clips on the timeline. Snap locks them to eighth notes.
- Mute and solo live in the track header. `M` and `S` do the same for the selected track.
- Save downloads a `.mellow` file. Open loads one back.
- Export writes `.wav` or `.mp3`.

The sketch named First Light is already on the timeline.

## Develop

```bash
npm install
npm run dev
```
